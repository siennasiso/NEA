# ChatGPT project archive

`conversations/` contains one Markdown accessibility snapshot for every conversation visible in the shared **COMP SCI NEA** project on 8 September 2026. These snapshots preserve user and assistant text, headings, tables, code and visible file references. They are not polished summaries and should be treated as historical source material.

`inventory/conversations.md` maps each snapshot to its original project URL.

`prior-partial-backup/` contains the earlier ZIP-based recovery made on 7 September 2026. It is retained because it includes structured recovered notes, validation metadata, checksums and a browser index. Its own status file correctly describes it as partial.

## Missing historical assets

Several chats reference generated flowcharts, annotated mockups, code files and ZIP downloads. Some remain visible only as filenames or buttons and currently display `Could not load image`; their download controls no longer return a file in the shared project. This limitation is recorded rather than silently substituting a different asset.
