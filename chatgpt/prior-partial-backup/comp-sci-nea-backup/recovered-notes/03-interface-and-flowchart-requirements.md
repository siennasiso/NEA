# Interface and flowchart requirements

> RECOVERED NOTES — newly organised on 7 September 2026 from the visible source excerpts. This is not an original document, a full transcript, or proof of completed work.

The visible requests cover login, registration, a homepage/dashboard, administrator animal management, an add-animal page, animal browsing/viewing, an individual animal page, and a questionnaire sequence. The questionnaire requests cover the start screen, an example question, and the results/animal pages after completion.

The user's repeated constraints are simplicity, an attractive pink theme, and an interface that is feasible in Streamlit. CHAT-03 specifically asks for a simpler administrator screen after rejecting a more complicated version. It also asks to change a home-related questionnaire item so it concerns the amount of space available. Exact replacement wording and answer options are absent.

CHAT-08 requests a combined registration/login flowchart with a purple theme. The same chat requests administrator, homepage/main-menu and animal-viewing flowcharts. Administrator functionality is discussed in terms of managing animals. Questionnaire completion and animal viewing are said to have separate sections; account viewing and logout may belong in the homepage section.

The user asks for exemplar-style annotations and high-quality design explanations. These requests establish intended deliverables; they are not the original annotations, diagrams or interface images. None of those generated or uploaded image files was available for this backup.

Sources: CHAT-03, CHAT-07, CHAT-08, CHAT-09 and CHAT-10.
