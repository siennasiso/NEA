# Project overview

> RECOVERED NOTES — newly organised on 7 September 2026 from the visible source excerpts. This is not an original document, a full transcript, or proof of completed work.

The project described in the visible conversations is an animal-adoption matching system for one shelter. The interface is intended to be simple, welcoming and pink-themed, and practical to implement with Streamlit. This is a record of stated plans, not proof that the system has been implemented.

The features explicitly listed in CHAT-13 are a clean user interface; user registration and login; administrator login; database storage for animal records, accounts and questionnaire answers; administrator CRUD functionality; input validation; a compatibility-scoring algorithm; and ranked animal recommendations.

CHAT-08 describes a homepage/main menu after login, links to the questionnaire, animal browsing and account viewing, a check of the user's session, and possible retrieval of the user's name and recent questionnaire information. The user also discusses placing account viewing and logout in that section.

CHAT-09 explicitly rejects the addition of an applications feature that was not present in the earlier designs. The same chat says the design should reflect competitor reports, stakeholder surveys, the client interview and success criteria. Those underlying documents and their findings are not available here.

Streamlit is a stated interface choice. SQLite is discussed as an option in CHAT-05, but the visible excerpt is a question, not a confirmed database decision.

Sources: CHAT-05, CHAT-08, CHAT-09, CHAT-13. See the source index for original visible wording.
