# NEA kit

Support material for finishing the PawMatch NEA. Nothing in here is coursework: it is structure, checklists and
templates. Everything that gets marked (pseudocode, code, test plans, write-up) is written by Sienna.

| File | Use it for |
| --- | --- |
| `PawMatch-NEA-master.docx` | The whole final document. Analysis (from your original Word file) and Design (from your PDF) are carried over word for word; Development, Testing and Evaluation have their headings and tables ready. Every yellow [TO WRITE] box says what the marksheet wants there; delete each one once written. |
| `DESIGN-FIXES.md` | The eight gaps in the current design draft, as a checklist. |
| `BUILD-STAGES.md` | The five build stages, what to test in each, and how to save a snapshot of each stage. |
| `model-different-project.docx` | What top-band sections look like, worked on a different project (gym booking). Pattern only: write PawMatch in your own words. |
| `AI-USE-LOG.md` | How to record AI use the way JCQ requires, with a table to fill in. |

Order: design fixes first (about a week), then one build stage a week, writing each stage up the same week,
then final testing and the evaluation.
